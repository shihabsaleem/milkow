
# MILKOW PROJECT DOCUMENTATION
==============================

## 1. PROJECT OVERVIEW
Milkow is a smart milk operations management system built with Next.js, Tailwind CSS, Framer Motion, and Supabase. It manages daily delivery routes, customer ledgers, inventory pipelines, and automated billing.

## 2. DATA ARCHITECTURE & RELATIONSHIPS
The system uses a highly normalized relational PostgreSQL database (Supabase V6+).

### Core Tables:
- **Areas**: Physical delivery zones/routes.
- **Products**: Master catalog with price snapshots and real-time stock.
- **Customers**: Linked to an Area. Implements **Decimal Midpoint Indexing** (`delivery_order`) for infinite route re-ordering.
- **Inventory**: Supply pipeline tracking physical stock loading.
- **Deliveries**: Daily transaction headers (date, shift, customer).
- **Delivery Items**: Normalized line items for each delivery (Product, Qty, Unit Price).
- **Bills**: Financial aggregates. Supports spot billing and batch consolidation.
- **Bill Deliveries**: Junction table for granular mapping of deliveries to specific bills.
- **Payments**: Tracks collection events. Supports floating "Advance" payments.
- **System Settings**: JSONB storage for app-wide configuration and automation states.

### Relationships:
- `Delivery` belongs to `Customer`.
- `Delivery Item` belongs to `Delivery` and `Product`.
- `Bill` links to `Customer`.
- `Bill Deliveries` maps `Bill` <-> `Delivery` (M2M).
- `Payment` links to `Customer` and optionally to a `Bill`.
- Financials are calculated via the **`customer_financials` view**, incorporating past outstanding and credits.

## 3. PAGE DIRECTORY (app/)
- **/login**: Authentication page using Supabase Auth.
- **/** (Dashboard): Real-time financial overview (Receivables vs. Advances), inventory pipelines, and delivery summaries.
- **/inventory**: Master stock management and price control.
- **/customers**: Searchable directory with route filtering.
- **/customers/[id]**: Comprehensive customer profile, balance tracking (Debt/Credit), and historical ledger.
- **/delivery**: Mobile-optimized route tracking with **localStorage Route Persistence** and **Silent background synchronization**.
- **/billing**: Collection dashboard with UPI QR generation and WhatsApp integration.

## 4. CORE FUNCTIONS & LOGIC
### Automation (lib/automation.ts)
- `resetDailyRoute()`: Pre-populates daily delivery records based on customer frequency.
- `generateDailyBills()`: Automated nightly billing consolidation.
- `deductInventoryOnDelivery()`: Real-time stock decrementing upon successful delivery.

### Intelligence & UX
- **Financial View**: Direct database calculation of balances to prevent fan-out errors.
- **Midpoint Indexing**: `delivery_order` uses `DECIMAL(20,10)` for sub-millisecond route optimization.
- **Route Persistence**: The app remembers the active delivery route across sessions and refreshes.
- **Silent Refresh**: Updates to delivery items occur without layout shifts or skeleton flashes.

## 5. UI/UX COMPONENTS
- **BottomNav**: Sticky mobile navigation.
- **Modal**: Universal interaction patterns.
- **Preloader**: Auth session hydration state.
- **Framer Motion**: Smooth gestural animations.
